Create a separate Qobuz query for each researched recording, up to four queries. Qobuz matches query words strictly: use only composer surname and conductor surname (for example Beethoven Honeck, Beethoven Vanska, Beethoven Ansermet). Do not include label names, orchestra names, opus numbers or Symphony No. wording: those often hide valid releases with differently written titles. The album selector will verify the work and edition from the returned candidates. When a work has no conductor (a solo, chamber or concerto recording), use the soloist's or ensemble's surname or name instead.

Also return the user's hard catalogue constraints; the app enforces them as filters on every Qobuz search:
- labels: record labels the user explicitly restricts the results to ("on Pentatone", "Pentatone releases"), by the label's usual name. Empty unless the user asked for a label; never add a label only because the research mentions it.
- released_within_years: N when the user asks for releases or recordings of the last N years ("last ten years" gives 10).
- released_from_year / released_to_year: an explicit range of years. A recording date gives only a lower bound (a recording may be released later), so never set released_to_year from one.
Use empty or null for anything the user did not state as a requirement. Preferences ("ideally", "preferably") and vague words ("recent", "modern") are not filters.
