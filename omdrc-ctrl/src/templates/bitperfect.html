Bit-perfect check

Plays a known signal through a chosen path and records the actual bytes on the USB wire to the DAC — the last point the host controls. Beyond it sit only the controller's DMA engine and the DAC's receiver, neither of which can alter a PCM payload. The verdict compares those bytes against the reference; the byte view below lets you see them side by side.

Before the stream: the untrimmed wire bytes

Alignment throws away everything the tap saw before the first reference byte — attach noise, then whatever the audio stack emitted ahead of the music. The verdict says nothing about those bytes, so here they are. There is no reference column: before the stream starts there is nothing to compare against. Rows before the anchor are marked trimmed.
