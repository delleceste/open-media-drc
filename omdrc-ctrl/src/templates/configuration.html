Install room-correction measurements and filters

In REW choose File → Export all measurements as text. Export unsmoothed measurements made at 48 kHz or below into a folder named <geometry>.<session>.txts, beside the matching <geometry>.<session>.mdat. Select their parent folder to fill both fields automatically, or select the .txts folder and then its exact matching .mdat.

Exactly one file for every role

L.txt · R.txtLR.txt or L+R.txtFLX-trimmed.txtFRX-trimmed.txtL.filtered.txt · R.filtered.txtmatching aggregate.filtered.txtFLX-trimmed-48k.wavFRX-trimmed-48k.wav

.txt and letter case are optional. Use L+R.remeasured.txt for a fresh corrected room measurement. Do not mix LR vector-average and L+R sum names. Both WAV filenames must declare the same sample rate, and each filter TXT must be the exported response of its WAV.
