# Artists and the labels they are known by, for the Qobuz search field.
#
# Typing (or completing) one of these names offers its labels as filter
# chips, because Qobuz's own search cannot search by label.  One line each:
#   Artist: Label, Label
# A label is matched as whole words, ignoring case, inside the label name
# Qobuz reports ("Blue Note" finds "Blue Note Records").  "#" starts a comment.
#
# Deliberately short: only records that matter in history.  What is played
# beyond this goes to a small ring of learned pairs (qobuz-artist-labels.json)
# that forgets its oldest entries; this file never grows by itself.
