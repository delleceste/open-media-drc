# Terminal client

Run `omdrc-ctrl/tools/omdrc-tui` in an interactive terminal, or install it as `omdrc-tui` with `sudo cmake --install build --component omdrc-tui` (the regular CMake install includes it too). The `omdrc-tui-install` build target also installs this component when the install prefix is writable. It opens Now playing and connects to `http://localhost:9090`; use `--server http://your-box:9090` for another box. Python 3 is required. Covers require `chafa` (`pkg install chafa` on FreeBSD); high resolution Sixel covers also require a compatible terminal such as Konsole. CMake warns if `chafa` is missing but still installs the client. Display preferences live in `~/.config/omdrc-tui/config.json`. A server address changed in Configuration applies to the current session; pass `--server` on later launches to use a remote box. Set up Qobuz sign-in, AI provider and audio hardware in the phone UI.

F1–F4 open Library, Now, read-only Room correction and Configuration. The TUI enables terminal focus reporting: when the terminal window loses focus, every view turns muted grey and covers (Sixel or symbols, in Now and the Library lists) turn dimmed greyscale; normal colors return when focus comes back. Page Up/Down and Ctrl+Left/Right move between those pages. The page shortcuts appear in the row below the cover. `Tab` cycles through all eight combinations of level bars, DR and balance; the `☷ +/- [Tab]` hint sits beside the live meters. In Library, `1`–`6` choose Search, Discover, Favourites, Chronology, Awarded and Review later. Discover remembers the selected genres across TUI restarts; clearing the selection is remembered too. `/` edits the query; Esc promptly cancels editing and highlights Search in the left pane. Tab or Down commits a changed query before moving to Filters. `f` edits filters; Labels offers the configured web UI labels, Space toggles them, `a` adds a custom label, Enter applies, and Esc goes back without changing the filter. Search and Discover remember their selected labels separately across TUI restarts. Filters shows the number of selected labels (for example, `2 labels`). Search label filters show Qobuz albums only because local MPD entries have no label metadata. Search shows a green indeterminate progress indicator while Qobuz responds. Result covers are separated by one terminal row, which the green selection border uses. Their metadata shows the DR log beside audio quality in a separate color: `DR=10` is exact, while `DR ~8` is estimated. The Sort control beside Filters switches between Qobuz relevance and time order: Tab or Right moves to Sort, and Enter toggles it. `s` is a shortcut for the same saved choice, `r` refreshes, `m` loads more, arrows select and Enter opens an album or folder. Moving the selection redraws Sixel covers in Konsole. `p` plays, `a` appends, `h` favourites and `b` bookmarks for Review later. Favourites has its own saved search query; changing tabs preserves each view's query. Switching away from Discover clears its image covers on the first Favourites frame. In Review later, `x` edits or removes a bookmark.

In Now, actions form a vertical list: Up/Down select and Enter activates. Previous and next share one `|<  >|` row; select either icon with Up/Down, or use `[` and `]`. Left/Right seek by ten seconds from anywhere on Now playing; the selectable Seek row shows track progress, and Enter opens the numeric seek prompt. Space toggles playback from any view (except while editing Search text or selecting genre or label filters), `s` stops, `i` opens album details, `R` opens Research music and `M` starts a streamed album DR measurement. A separator divides transport from album actions. The applied DRC status sits below the actions and is read only. Audio format color follows the app’s quality tiers. Research music clears the cover and uses a bordered, scrollable text area with headings, lists and source links. If AI credentials are missing, it opens the browser AI setup automatically and resumes research after setup is saved. Configuration → AI provider (`a`) opens that setup at any time. Claude account mode requires a Claude Code login on the server; OpenAI and Claude API modes accept an API key in the browser settings. Research shows elapsed time and clears its busy state if the provider fails. Left/Right change section, Up/Down scroll, and Esc returns to the opening page. Back cancels an unfinished research request.

The balance bubble follows the latest 300 ms RMS frame, while its separate numeric average uses the selected window in Configuration. The bottom panel uses the same live MPD FIFO streams and three-second DR blocks as the phone UI. Away from Now, after the configured 2, 5 or 10 minutes it asks whether to keep estimating. If unanswered for a minute it releases the DR listener, allowing the server to stop computing when no other client is listening. Returning to Now starts a fresh listener. Album DR measurement is separate and works only for streamed tracks the server can fetch again.

The Now page shows the applied DRC path from `/now`: **DRC OFF · direct** when correction is off, or the active rate, filter set, design and attenuation. Bars and status text use the app's dark or light colours while retaining the terminal's own background. Automatic theme follows `COLORFGBG` when the terminal provides it; Configuration → Theme (`z`) can select light or dark explicitly.

With `chafa`, Konsole uses Sixel pixel graphics for covers in Now and the Library lists. The image is drawn after curses refreshes the text and is redrawn when the cover or layout changes, including a terminal resize. Configuration → Cover mode (`p`) cycles auto, Sixel and symbols; auto selects Sixel when Konsole identifies itself and symbols elsewhere. Symbols remain available for terminals without Sixel support. Sixel covers are trimmed to whole six-pixel bands so they never cover the selection border on the row below. Press `C` in Now playing to enlarge the cover and hide the meters temporarily; `C` or Esc returns to the normal view. Sixel images keep their pixel detail and color palette; the symbols fallback uses two vertical samples per terminal cell and maps color to the terminal palette.

Cover requirements: Sixel needs a terminal that supports it; symbols work in other terminals. The TUI fetches Qobuz artwork directly from its image URL, so that URL must be reachable from the machine running the TUI. Local collection artwork comes from the controller and MPD: the controller tries MPD `albumart` (an external cover file), then `readpicture` (art embedded in the track). If neither exists, that local album has no cover to display. A failed Qobuz cover download shows “No cover”; failed local artwork shows a bordered `local` marker. Both are retried after 30 seconds while the result stays visible. Local artwork requires the indexed music files to remain mounted and readable by MPD.
