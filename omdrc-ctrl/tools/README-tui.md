# Terminal client

Run `omdrc-ctrl/tools/omdrc-tui` in an interactive terminal. It opens Now playing and connects to `http://localhost:9090`; use `--server http://your-box:9090` for another box. Python 3 is required; `chafa` is optional for colored cover art. Display preferences live in `~/.config/omdrc-tui/config.json`. A server address changed in Configuration applies to the current session; pass `--server` on later launches to use a remote box. Set up Qobuz sign-in, AI provider and audio hardware in the phone UI.

F1–F4 open Library, Now, read-only Room correction and Configuration. The same four pages are selectable in the row below the cover: Tab focuses it, Left/Right choose a page, and Enter opens it. `v` opens the visibility menu; `1`–`3` toggle level bars, DR and balance. In Library, `1`–`6` choose Search, Discover, Favourites, Chronology, Awarded and Review later. `/` edits the query, `f` edits filters, `r` refreshes, `m` loads more, arrows select and Enter opens an album or folder. `p` plays, `a` appends, `h` favourites and `b` bookmarks for Review later. In Review later, `x` edits or removes a bookmark.

In Now, actions form a vertical list: Up/Down select and Enter activates. Previous and next share one `|<  >|` row; select either icon with Up/Down, or use `[` and `]`. Left/Right seek by ten seconds from anywhere on Now playing; the selectable Seek row shows track progress, and Enter opens the numeric seek prompt. Space toggles playback, `s` stops, `i` opens album details, `R` opens Research music and `M` starts a streamed album DR measurement. A separator divides transport from album actions. The applied DRC status sits below the actions and is read only. Audio format color follows the app’s quality tiers. Research music clears the cover and uses a bordered, scrollable text area with headings, lists and source links. If AI credentials are missing, it opens the browser AI setup automatically and resumes research after setup is saved. Configuration → AI provider (`a`) opens that setup at any time. Claude account mode requires a Claude Code login on the server; OpenAI and Claude API modes accept an API key in the browser settings. Research shows elapsed time and clears its busy state if the provider fails. Left/Right change section, Up/Down scroll, and Esc returns to the opening page. Back cancels an unfinished research request.

The balance bubble follows the latest 300 ms RMS frame, while its separate numeric average uses the selected window in Configuration. The bottom panel uses the same live MPD FIFO streams and three-second DR blocks as the phone UI. Away from Now, after the configured 2, 5 or 10 minutes it asks whether to keep estimating. If unanswered for a minute it releases the DR listener, allowing the server to stop computing when no other client is listening. Returning to Now starts a fresh listener. Album DR measurement is separate and works only for streamed tracks the server can fetch again.

The Now page shows the applied DRC path from `/now`: **DRC OFF · direct** when correction is off, or the active rate, filter set, design and attenuation. Bars and status text use the app's dark or light colours while retaining the terminal's own background. Automatic theme follows `COLORFGBG` when the terminal provides it; Configuration → Theme (`z`) can select light or dark explicitly.

With `chafa`, Konsole uses Sixel pixel graphics for covers. The image is drawn after curses refreshes the text and is redrawn when the cover or layout changes. Configuration → Cover mode (`p`) cycles auto, Sixel and symbols; auto selects Sixel when Konsole identifies itself and symbols elsewhere. Symbols remain available for terminals without Sixel support. Press `C` in Now playing to enlarge the cover and hide the meters temporarily; `C` or Esc returns to the normal view. Sixel images keep their pixel detail and color palette; the symbols fallback uses two vertical samples per terminal cell and maps color to the terminal palette.
